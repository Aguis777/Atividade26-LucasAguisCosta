## `01` — SOBRE O PROJETO

Este repositório apresenta os conteúdos desenvolvidos durante a **Atividade 26 de Programação de Computadores (PC1)**.

O foco principal foi aprender e praticar a criação de interfaces gráficas utilizando Python e a biblioteca Tkinter.

Durante o desenvolvimento, explorei diferentes componentes visuais, funções e recursos que permitem transformar códigos em aplicações interativas.

## `02` — TECNOLOGIAS UTILIZADAS

| Tecnologia | Aplicação |
|:---|:---|
| Python | Linguagem de programação |
| Tkinter | Criação de interfaces gráficas |
| GitHub | Organização e armazenamento dos códigos |
| Markdown | Documentação do projeto |

## `03` — CONTEÚDOS APRENDIDOS

Ao longo da atividade, desenvolvi conhecimentos importantes:

- **Janelas:** criação e personalização de interfaces.
- **Labels:** exibição de textos.
- **Buttons:** execução de ações por meio de botões.
- **Entry:** entrada de informações.
- **Listbox:** organização de listas.
- **Checkbutton e Radiobutton:** seleção de opções.
- **Combobox:** criação de menus de seleção.
- **Frames:** organização dos componentes.
- **Pack, Grid e Place:** posicionamento de elementos.
- **Funções:** execução de comandos e ações.
- **Messagebox:** exibição de mensagens.
- **Validação:** verificação dos dados inseridos.
- **Variáveis Tkinter:** armazenamento e atualização de valores.

## `04` — DESENVOLVIMENTO DA ATIVIDADE

A atividade foi desenvolvida por meio de exercícios práticos, começando com interfaces simples e avançando para aplicações mais completas.

Durante esse processo, pratiquei a criação de janelas, utilização de componentes, organização visual e desenvolvimento de funcionalidades.

Cada exercício apresentou uma oportunidade de aplicar a lógica de programação e entender melhor como os elementos de uma interface gráfica trabalham juntos.
